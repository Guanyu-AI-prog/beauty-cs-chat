## 一、今日重点

### 1. 读图取证，定位 OpenCode 会话卡死

用户贴了 OpenCode 截图（`OC | 查看本机磁盘占用情况 (fork #1)`）。会话本身在做两件事：探测本机 `127.0.0.1:3000` 的 Open WebUI、拿 token 调 `/api/v1/models`。

| 轮次 | 问题 | 处置 |

### 3. 自建轻量中文前端（替代方案）

```
浏览器 → :3000 web/app.py（uvicorn，31.5MB，systemd 托管）
             └─ POST /api/chat → SSE 透传 → :8001 openai_adapter.py → SimpleRAG
```

- 前端**单文件**（HTML/CSS/JS 全内联），零依赖零构建；内置极简 Markdown 渲染，把回答末尾的 `参考来源：` 解析成金色引用标签。

- 端口沿用 3000，访问地址不变；`/etc/systemd/system/beauty-chat-web.service` 负责开机自启与崩溃拉起。

## 三、踩坑记录

### A. Open WebUI 定制版（`ghcr.nju.edu.cn/open-webui/open-webui:main`，v0.12.3，commit `91ea4e34`）

1. **免密回退已被移除**：`open_webui/utils/auth.py` 里没有"`WEBUI_AUTH=false` 时自动以首个 admin 身份登录"的分支。前端 `features.auth=false` → 跳过登录页直接自动登录 → `GET /api/v1/auths/` 必 401 → 永远等不到 `user-join` 事件 → 卡死在启动页。
2. **`WEBUI_AUTH=false` + 库里已有用户 = 死结**：`signup` 被 403 拒（`You do not have permission...`），`signin` 被 400 拒（`You can't turn off authentication because there are existing users...`）——取 token 的两条路同时断。**第一用户注册只能用一次**。
3. **免密模式的内置账号是 `admin@localhost` / `admin`**（写死在 `routers/auths.py`）。该账号存在时走"校验密码"分支，不存在且库里有别的用户时直接报错。
4. **公共配置端点搬家**：定制版把 `/api/v1/config` 改成 `/api/config`、`/api/v1/version` 改成 `/api/version`。老路径会被 SPA 兜底成 HTML（表现为"接口返回 HTML"这种怪现象）。排查时要先确认路径属于哪个版本。
5. **前端没有 i18n 语言包**：产物里搜不到任何 locale 资源 → 界面英文**不是设置问题**，改配置也翻不了中文。
6. **数据没有挂卷**：`Mounts` 为 `[]`，`webui.db` 在容器可写层 → 重建容器即丢用户与聊天记录。必须先备份或先加 `-v`。
7. **`WEBUI_SECRET_KEY` 为空且不落库** → 容器一重启，所有已签发 token 立刻失效。
8. **健康检查 jq 报错**：镜像 healthcheck 用 `jq -ne`，部分版本 jq 不支持 `-ne` → 启动期报 `jq: error (at <stdin>:0): break`，但服务本身正常，别被健康状态误导。

### B. 网络与 GitHub

9. **GitHub 直连被阻断**：本机 DNS 把 `github.com` / `api.github.com` 解析到 `20.205.243.x`（香港节点），TCP/HTTPS 均失败；改走 `140.82.112.x`（美国节点）→ 200。已在 `/etc/hosts` 追加带标记的两行映射，备份在 `/etc/hosts.bak-before-github`。**该 IP 会变，需要时重新探测。**
10. **GitHub API 偶发 `IncompleteRead`**：大 JSON 响应（vault 目录树 300KB+）会中途断流 → 加重试循环即可；`git clone` 也可能 `fatal: early EOF`，此时改用 Contents API 单文件写入更快。

### C. 工具与操作

11. **`pkill` / `pgrep -f` 会匹配到自己的 shell**：命令串里出现 `pkill -f "remote-debugging-port=9222"` 时，模式串本身就在当前 bash 的命令行里 → shell 自杀（今天误杀 3 次，报 `Command terminated by signal SIGTERM`）。**修法**：用括号断开匹配（`pgrep -f "922[2]"`）、按端口取 PID（`ss -ltnp`）、或 `--resolve`/`-c credential.helper` 规避。
12. **内置 Browser 能力本会话不可用**：`tool_search` 查不到 browser 工具。替代方案：无头 Chrome + CDP（`--remote-debugging-port` + WebSocket），可注入 token、读 DOM、模拟输入、回车发送、截图。

### D. 安全

13. **推送前扫描拦下真实密钥**：`demo/legacy/rag_agent_system.env.bak` 内含两把明文 SiliconFlow Key（`SILICONFLOW_API_KEY` / `LLM_API_KEY`）。处置：删掉该备份文件、`.gitignore` 加固为 `.env` / `.env.*` / `*.env` / `*.env.bak`、改用 `.env.example` 模板；远端复查这些路径全部 404。**公开仓库前必须做这步扫描。**
14. **凭证不要复制**：本机凭证在 `/root/.git-credentials`（root 可读、admin 不可读）。用 `sudo env HOME=/root git push` 走 root 的 `credential.helper`，令牌不落到第二个路径。
